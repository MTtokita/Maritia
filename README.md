# Maritia - Gerenciador de Ficha de RPG

## Objetivo do Sistema
O **Maritia** é uma aplicação web desenvolvida para gerenciamento dinâmico de fichas de personagens de RPG. O sistema permite acompanhar atributos, inventário, status secundários (HP, Mana, Estamina, XP) e personalizar visualmente a interface da ficha em tempo real.

## Principais Funcionalidades
- **Autenticação de Usuários:** Cadastro, login e redefinição de senha via Firebase Auth.
- **Gestão de Personagem:** Controle de atributos, nível, experiência e pontos de vida/recursos.
- **Inventário e Perícias:** Adição, edição e gerenciamento de itens e habilidades especializadas.
- **Personalização de Interface:** Controle dinâmico de cores de borda, fundo, sombras e escolha de fontes personalizadas.
- **Persistência de Dados:** Sincronização automática em tempo real com o Cloud Firestore.
- **Compatibilidade:** Tratamento de dados legados e suporte a múltiplos navegadores.

## Tecnologias Utilizadas
- React / Vite
- Firebase (Firestore & Auth)
- CSS3 / HTML5
- Vercel (Hospedagem e Deploy)
